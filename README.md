Итак, вот вам инструкция по установке и запуску данного приложения. Попытаюсь все максимально понятно объяснить:
1. Качаем OpenServer
2. Качаем ZIP-файлом данный репозиторий
3. Распаковываем архив в нужной вам папке
4. Переносим папку autobaseBack в папку C:/(путь к папке)/OSPanel/domains
5. Запускаем OpenServer и идем в PhpMyAdmin
6. Создаем новую БД "autobase" без кавычек (важно именно так назвать!)
7. Открываем вкладку "Импорт"
8. Импортируем файл autobase.sql
9. Переходим в IDE и в нем открываем папку, где у вас проект
10. В терминале пишем:
`npm install`
11. После установки всех зависимостей мы пишем:
`npm run dev`
12. Готово
